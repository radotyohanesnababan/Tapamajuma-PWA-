Sistem CBT terbagi menjadi 3 fase utama yang harus dilakukan secara berurutan.

01
Fase Pertama

Persiapan Ujian

Memeriksa & memvalidasi paket soal sebelum ujian dimulai

1.1
Membuka Daftar Paket Ujian

Masuk ke menu CBT / Daftar Ujian untuk melihat seluruh paket ujian yang tersedia dalam tabel lengkap.

Judul Ujian Mata Pelajaran Soal Durasi Status
UTS Matematika Kelas 7 Matematika 50 90 mnt DRAFT
Ulangan IPA Bab 3 IPA 40 60 mnt DRAFT
💡 Ujian yang belum dimulai akan berstatus DRAFT. Pastikan semua informasi sudah benar sebelum melanjutkan ke langkah berikutnya.
1.2
Melakukan Pratinjau (Preview) Soal

Di kolom Aksi, klik tombol ikon Mata (Eye) pada paket ujian yang dipilih untuk membuka pratinjau soal.

Kolom Aksi: 👁 Preview ▶ Rilis Token 🗑 Hapus

Jendela pop-up menampilkan seluruh soal. Periksa hal-hal berikut:

  • Teks pertanyaan — pastikan tidak ada typo atau konten yang hilang
  • Pilihan ganda (A, B, C, D, E) — terbaca dengan benar
  • Kunci Jawaban — ditandai warna hijau + ikon ✓
  • Gambar atau media pendukung — pastikan tidak ada yang rusak
✅ Lakukan pratinjau sebelum ujian dibagikan ke siswa untuk menghindari kesalahan fatal yang tidak bisa diperbaiki di tengah ujian.
02
Fase Kedua

Pelaksanaan Ujian

Mengontrol kelas dan memonitor siswa secara langsung (live)

2.1
Merilis Token Ujian (Membuka Akses)

Lakukan sesaat sebelum siswa mulai mengerjakan, saat pengawas sudah berada di dalam kelas.

  • Klik tombol biru ▶ RILIS TOKEN pada baris ujian yang ingin diaktifkan
  • Sistem memproses dan mengaktifkan ujian tersebut
  • Status berubah dari DRAFT → ACTIVE
Sebelum ▶ Rilis Token DRAFT
→
Sesudah 🖥️ Monitor Live ACTIVE
📋 Catatan Pengawas: Token ujian (kombinasi huruf/angka) otomatis ter-generate. Tulis di papan tulis atau tampilkan di proyektor agar siswa bisa masuk.
2.2
Memonitor Ujian Berlangsung (Live Control)

Setelah ujian berstatus ACTIVE, tombol berubah menjadi 🖥️ MONITOR LIVE. Klik untuk membuka panel pemantauan.

Fitur yang tersedia di panel Live Control:

  • Melihat daftar siswa yang sedang online mengerjakan soal secara real-time
  • Memantau sisa waktu ujian masing-masing siswa
  • Me-reset sesi jika komputer siswa mengalami masalah teknis mendadak
03
Fase Ketiga

Pasca Ujian

Laporan otomatis, nilai real-time & cetak PDF tanpa koreksi manual

⚡ Ini adalah fitur unggulan CBT TAPAMAJUMA. Begitu siswa menekan tombol "SELESAI", nilainya langsung masuk ke server detik itu juga. Tidak perlu koreksi manual sama sekali.
3.1
Membuka Laporan Nilai

Pada daftar ujian, klik ikon Grafik Batang (BarChart) pada ujian yang sudah selesai untuk membuka halaman laporan.

Kolom Aksi: 👁 Preview 📊/home/radotnababan/Downloads/fase0-paket-ujian.html Laporan

Layar akan berpindah ke halaman Laporan Hasil Ujian.

3.2
Membaca Data Hasil Ujian

Tabel otomatis menampilkan peringkat siswa dari nilai tertinggi ke terendah.

3.4
Mencetak Berita Acara / Laporan Nilai (PDF)

Klik tombol di pojok kanan atas halaman laporan untuk menghasilkan dokumen siap cetak.

🖨️ Cetak PDF

Sistem secara otomatis akan:

  • Menyembunyikan tombol pencarian, filter, dan navigasi yang tidak perlu
  • Mengubah tampilan menjadi format kertas A4 yang rapi (hitam-putih/warna)
  • Menambahkan Header Resmi — "LAPORAN HASIL UJIAN CBT" beserta detail mata pelajaran & kelas yang difilter
🖨 Guru cukup menekan "Print" di browser — cetak ke printer fisik atau simpan sebagai file PDF langsung dari tampilan tersebut.
⚠  Info Tambahan: Menghapus Ujian

Jika paket ujian sudah tidak terpakai atau terdapat kesalahan fatal, Guru dapat menghapusnya dengan menekan tombol Tempat Sampah (Trash) berwarna merah di kolom Aksi.

PERINGATAN KRITIS: Menghapus paket ujian akan menghapus seluruh data nilai siswa yang terkait secara permanen dan tidak dapat dikembalikan. Sistem akan menampilkan dialog konfirmasi terlebih dahulu — baca dengan teliti sebelum melanjutkan.
